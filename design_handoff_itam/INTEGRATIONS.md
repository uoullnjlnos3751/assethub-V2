## 1. Active Directory (LDAPS)

```
โดเมน       trrgroup.com
Server      ldaps://dc01.trrgroup.com:636
Base DN     OU=Users,DC=trrgroup,DC=com
บัญชี        svc-itam@trrgroup.com (อ่านอย่างเดียว)
ซิงก์        ทุก 4 ชั่วโมง · ล่าสุด 08:00 น. · ใช้เวลา ~48 วินาที
บัญชีทั้งหมด 1,842
```

**การจับคู่ฟิลด์**
| ฟิลด์ในระบบ | AD attribute |
| --- | --- |
| ชื่อ–นามสกุล | `displayName` |
| อีเมล | `mail` |
| รหัสพนักงาน | `employeeID` |
| แผนก | `department` |
| ตำแหน่ง | `title` |
| หัวหน้างาน | `manager` |
| เบอร์ภายใน | `telephoneNumber` |
| สถานที่ทำงาน | `physicalDeliveryOfficeName` |
| รูปโปรไฟล์ | `thumbnailPhoto` |
| **บริษัท** | `company` ← ใช้กำหนด company scope |
| กลุ่มสมาชิก | `memberOf` ← ใช้กำหนด role |
| สถานะบัญชี | `userAccountControl` |

**พฤติกรรมที่ต้องมี**
- ระบบอ่านอย่างเดียว ห้ามเขียนกลับ AD
- ไม่มี `thumbnailPhoto` → ใช้ตัวย่อชื่อ 2 อักษรแทน
- บัญชีใหม่ใน AD → สร้างผู้ใช้ในระบบอัตโนมัติ บทบาทเริ่มต้น USER
- บัญชีถูก disable → ระงับสิทธิ์ทันที + ยกทรัพย์สินที่ถือครองขึ้นเป็นรายการรอเรียกคืน
- แผนกเปลี่ยน → ย้ายทรัพย์สินตามผู้ใช้
- `memberOf` เปลี่ยน → เปลี่ยน role ตาม mapping
- แผนกไม่ตรงผังองค์กร → ยกขึ้นเป็นรายการ "รอตรวจสอบ" ไม่บล็อกการใช้งาน
- ทุกการเปลี่ยนแปลงบันทึกลง AuditLog พร้อมค่าเดิม/ค่าใหม่ (source = ADSync)

**AD ไม่มีโลโก้บริษัท** — ต้องอัปโหลดในระบบที่ ตั้งค่า › ทั่วไป

## 3. GLPI Agent

```
Server     glpi.trrgroup.com
Agent      v1.6–1.7
รายงาน      3,642 จาก 4,182 เครื่อง
```
ดึง: Serial · Service Tag · CPU · RAM · Disk · OS · รายการซอฟต์แวร์ที่ติดตั้ง

**กฎ:** เครื่องที่ไม่ส่งข้อมูลเกิน 30 วัน ต้องยกขึ้นเป็นรายการเตือน (ปัจจุบัน 128 เครื่อง) — อาจถูกถอน Agent หรือเลิกใช้งาน

ข้อมูลจาก GLPI **ทับ** ข้อมูลสเปกที่กรอกมือได้ แต่ต้องไม่ทับข้อมูลการเงินหรือผู้ครอบครอง

## 4. Power Automate + 5. Microsoft Forms

Flow 6 ตัว · เรียกใช้ ~1,284 ครั้ง/เดือน · สำเร็จ 99.4%

**ลำดับงานส่งมอบ**
```
1. ITAM สร้างใบส่งมอบ (FormID)                      [ITAM]
2. เรียก Flow ส่งอีเมลพร้อมลิงก์ MS Form            [ITAM → Flow]
3. ผู้ใช้กดยืนยันใน MS Form                          [ผู้ใช้]
4. Flow เขียนเวลายืนยันกลับเข้า ITAM ผ่าน API       [Flow → ITAM]
5. ITAM เปลี่ยนสถานะเป็น "รับเครื่องไปแล้ว"          [ITAM]
6. ITAM ตัดสต็อกอุปกรณ์ต่อพ่วง                       [ITAM]
```

**สัญญา API ที่ Flow ต้องใช้**
```
POST /api/deploys/confirm/:token
Header: X-Api-Key: <itam-flow>
Body:   { confirmedAt, confirmedBy, signatureUrl?, remark? }
```

**อีเมลต้องส่งถึง:** ผู้รับ · สำเนา: หัวหน้า (managerEmail), HR (hrEmail), ฝ่ายไอที (itEmail)

**หัวเรื่องมาตรฐาน:** `[IT] ยืนยันการรับมอบอุปกรณ์ · {{FormID}} · {{Comname}}`

**ทางเลือกยืนยันอื่นที่ต้องรองรับ:** เซ็นบนแท็บเล็ตหน้าเคาน์เตอร์ · สแกน QR บนใบส่งมอบเปิดฟอร์มบนมือถือ

**ผลจาก MS Form เก็บที่:** SharePoint › ITAM-Forms

## 9. ระบบจัดซื้อ (PO) — ยังไม่ตั้งค่า

รองรับ REST API หรือไฟล์ CSV · ประโยชน์: ดึงใบสั่งซื้อมาสร้างทะเบียนทรัพย์สินอัตโนมัติ ลดการคีย์ซ้ำ

## 10. ระบบ HR / ผังองค์กร — ยังไม่ตั้งค่า

รองรับ REST API หรือไฟล์ CSV รายวัน · ประโยชน์: รู้วันเริ่มงานและวันลาออกล่วงหน้า เพื่อเตรียมเครื่องและเรียกคืนอุปกรณ์ทันเวลา · แก้ปัญหาแผนกไม่ตรงผังองค์กร
