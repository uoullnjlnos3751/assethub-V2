# เอกสารประกอบระบบ TRR Asset Register

โฟลเดอร์นี้เก็บ **ทุกอย่างที่ใช้ในการออกแบบระบบ** ไว้ที่เดียว
ตั้งแต่ข้อมูลที่เก็บจากระบบต้นแบบ ไปจนถึงข้อกำหนดของระบบที่สร้างจริง
โค้ดที่รันได้อยู่นอกโฟลเดอร์นี้ (`db/`, `server/`, `public/`, `test/`)

## เริ่มอ่านจากตรงไหน

| ถ้าคุณกำลังจะ… | อ่านไฟล์นี้ |
|---|---|
| เพิ่มตาราง/คอลัมน์ใหม่ | `spec/data-model.md` |
| เขียนหน้าใหม่หรือเรียก API | `spec/api-reference.md` |
| ทำหน้าจอใหม่ให้เข้าชุดกับของเดิม | `spec/ui-spec.md` |
| วางแผนงานรอบถัดไป | `spec/roadmap.md` |
| ดูว่าต้นแบบมีเมนูอะไรบ้าง | `reference/invgate-menu-notes.md` |
| หาว่าไอคอนไหนใช้กับเมนูไหน | `reference/invgate-icons.md` |
| ดูสีและระยะห่างที่ต้นแบบใช้ | `reference/invgate-design-tokens.md` |

## โครงสร้าง

```
docs/
├── README.md                       ไฟล์นี้
│
├── reference/                      ข้อมูลที่เก็บจากระบบต้นแบบ InvGate
│   ├── invgate-menu-notes.md       โครงเมนูทั้งหมด 10 หมวด + เมนูย่อยทุกชั้น
│   ├── invgate-icons.md            ชื่อไฟล์ไอคอนจริงที่ดึงจาก DOM + รูปที่เป็น
│   ├── invgate-design-tokens.md    สี ระยะห่าง และตัวอักษรที่วัดจากหน้าจริง
│   ├── invgate-teardown.html       เอกสารถอดโครงหน้าเว็บ (เปิดด้วยเบราว์เซอร์)
│   ├── invgate-menu-map.html       แผนที่เมนูพร้อมภาพประกอบฝังในไฟล์
│   ├── screens/                    ภาพหน้าจอต้นแบบ 9 หน้า (JPG ขนาดเล็ก)
│   └── screens-hires/              ภาพหน้าจอต้นแบบ 11 หน้า (PNG ความละเอียดสูง)
│
├── design/                         งานออกแบบของเรา
│   ├── ui-template.html            ต้นแบบ UI หน้าเดียวจบ (เปิดดูได้เลย ไม่ต้องมีเซิร์ฟเวอร์)
│   ├── mockups/                    ภาพร่างระหว่างออกแบบ v3–v5
│   └── app-screens/                ภาพหน้าจอจากระบบจริงที่รันอยู่
│
└── spec/                           ข้อกำหนดของระบบที่สร้างจริง
    ├── data-model.md               ตาราง VIEW Trigger ความสัมพันธ์
    ├── api-reference.md            ทุก endpoint พร้อม parameter และ state machine
    ├── ui-spec.md                  Design tokens โครงหน้า และกติกาการเขียนหน้าใหม่
    └── roadmap.md                  แผนเฟส 2 และข้อควรระวังก่อนขึ้นใช้งานจริง
```

## หมายเหตุเรื่องข้อมูลอ้างอิง

ข้อมูลใน `reference/` เก็บจากระบบทดลองของ InvGate เพื่อ **ศึกษาโครงและลำดับการใช้งาน** เท่านั้น

- ไอคอนในระบบเราวาดขึ้นใหม่ทั้งชุด ไม่ได้คัดลอกไฟล์ SVG ของต้นแบบ
- ข้อความ ตราสัญลักษณ์ และโค้ดของต้นแบบไม่ได้ถูกนำมาใช้
- เก็บไว้เป็นบันทึกการออกแบบ ไม่ใช่ส่วนหนึ่งของระบบที่ส่งมอบ

## โฟลเดอร์อื่นในโปรเจกต์ที่ไม่ใช่ส่วนของระบบ

| โฟลเดอร์ | คืออะไร |
|---|---|
| `web/` | โครง React + Vite ที่ลองไว้ช่วงต้น ไม่ได้ใช้ในระบบปัจจุบัน (ระบบจริงเป็น Vanilla JS ใน `public/`) ลบทิ้งได้ถ้าไม่ต้องการ |
| `design-reference/` | โฟลเดอร์เก่า ย้ายเนื้อหาเข้ามาไว้ใน `docs/reference/` แล้ว เหลือแต่โฟลเดอร์ว่าง ลบทิ้งได้ |
