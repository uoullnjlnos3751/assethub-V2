Assets

ศูนย์กลางจัดการ Configuration Item (CI) ทางกายภาพและ Cloud ทั้งหมด

เมนูย่อยPathรายละเอียด
Assets#/assets/explorerExplorer รายการ Asset ทั้งหมด (View เริ่มต้น "All Assets")
Cloud Assets#/assets/cloud/explorerExplorer สำหรับทรัพยากร Cloud
Discovery#/assets/discoveryรายการอุปกรณ์ที่ค้นพบจาก Network Scan (Name/Status/Type/IP/MAC/Manufacturer/Model/Serial/Source)

ฟีเจอร์ร่วมของทุก Explorer

Custom views
สลับ/สร้าง View พร้อม Filter ที่บันทึกไว้
New CI ▾
สร้าง CI ใหม่ หรือ Import CIs จากไฟล์ภายนอก
Tags
Smart tags (Auto เช่น Manufacturer/Location) และ Manual tags (Employee/Manager) พร้อม Manage/New tag

Software

จัดการ Software Inventory, Deployment และ Compliance ทั้งหมด

เมนูย่อยPathรายละเอียด

Deployment ▸ Packages#/software/deployment/packagesคลัง Package สำหรับ Deploy
Databases#/software/databases/explorerExplorer Database Instance

10

Settings

ศูนย์ Configuration ทั้งหมดของระบบ แบ่งเป็น 10 หมวดหลัก แต่ละหมวดมีเมนูย่อยด้านขวา

10.1 · General

PreferencesInterface design (Classic/Veil), Company name, Attachment file size ฯลฯ
Locationsจัดการสถานที่ตั้งของ CI
Tagsกำหนด Tag สำหรับจำแนก CI
Documentsจัดการ Template สำหรับสร้างเอกสาร

10.2 · Users

Usersสร้าง/Import/จัดการผู้ใช้ (แยก Technicians / Users)
Authenticationตั้งค่าการยืนยันตัวตนและการลงทะเบียน
Directory servicesImport ผู้ใช้และเชื่อมต่อ Directory Service (AD/LDAP/SSO)
Permissionsจัดการ Role และสิทธิ์การใช้งาน

10.3 · CIs

GeneralGeolocation, Duplicate detection, Auto merge, Auto owner assignment
Fieldsกำหนด Field ของ CI เอง
Asset Typesกำหนดประเภท/หมวดหมู่ Asset
Healthกฎประเมินเงื่อนไขสุขภาพของ Asset
Lifecycleกำหนดสถานะวงจรชีวิตของ Asset
Inventory IDTemplate รหัส Inventory ID
Automationsกฎ Automation ตาม Event ที่เกิดขึ้น
Software meteringกำหนด Software/Device ที่ต้องวัดการใช้งาน
Depreciationตั้งค่าการคิดค่าเสื่อมราคา Asset

10.4 · Software Deployment

PreferencesConcurrency limit, Retry interval, Exclude tags
Security controlsตั้งค่าความปลอดภัยของ Software Deployment
Shared drivesจัดการ Shared drive สำหรับตัวติดตั้ง

10.5 · Discovery

Agent deploymentDeploy Agent: OS, Method (Manual/GPO/Remote via Proxy), Proxy/Server, Installation type
Proxiesจัดการ Proxy Server
Discovery sourcesเชื่อมต่อ/ตั้งค่ากระบวนการค้นหา Asset
SNMP Profilesกำหนดข้อมูลที่เก็บจากอุปกรณ์ Network
Printersจัดการเครื่องพิมพ์ที่ Agent/USB ตรวจพบ

10.6 · Tasks

Tasksตรวจสอบ/จัดการ Background Task ของการ Deploy

10.7 · Email

Outgoing emailตั้งค่า SMTP Server สำหรับส่งอีเมล

10.8 · AI Hub BETA

AI servicesเลือกผู้ให้บริการ AI (ปัจจุบัน "InvGate AI Service")
Featuresเปิด/ปิดฟีเจอร์: OS Updates summaries, Smart Recommendations, Smart search และอื่นๆ

10.9 · Integrations

Service Managementเชื่อมต่อ ITSM: InvGate Service Management (Enabled), Jira, ServiceNow, Zendesk
APIจัดการ API Access Credentials
Remote Desktopจัดการโปรแกรม Remote Desktop ที่รองรับ
Warranty APIsเชื่อมต่อ API ภายนอกเพื่อ Sync ข้อมูล Warranty

10.10 · System

Systemข้อมูล Product/Version (v3.20), Demo Mode, Subscription
Privacyการตั้งค่าความสอดคล้อง GDPR
EventsLog เหตุการณ์ฝั่ง Admin

ระบบที่เชื่อมโยง

InvGate Service Desk
waddles.sd.cloud.invgate.net
ระบบ ITSM/Helpdesk แยกต่างหาก เข้าถึงได้จากไอคอนล่างสุดของแถบเมนูซ้าย (ยังไม่ได้สำรวจเมนูย่อยในรอบนี้)
