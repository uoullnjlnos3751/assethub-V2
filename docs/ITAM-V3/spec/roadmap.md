## เฟส 2 — ที่ควรทำต่อ เรียงตามความคุ้มค่า

| ลำดับ | สิ่งที่ทำ | ทำไมถึงอยู่ลำดับนี้ | ต้องแตะอะไรบ้าง |
|---|---|---|---|
| 1 | **นำเข้าข้อมูลจาก Excel/CSV** | ตอนเริ่มใช้จริงต้องย้ายทะเบียนเดิมเข้ามา ถ้าไม่มีจะติดตั้งไม่ได้เลย | route ใหม่ + หน้าอัปโหลด + ตรวจข้อมูลก่อนบันทึก |
| 2 | **เข้าสู่ระบบด้วยบัญชี Microsoft 365** | องค์กรใช้ M365 อยู่แล้ว ลดการจัดการรหัสผ่านและได้ MFA ฟรี | Entra ID App Registration + OIDC ใน `auth.js` |
| 3 | **Agent เก็บข้อมูลเครื่องอัตโนมัติ** | ตอนนี้ซอฟต์แวร์/สเปกต้องกรอกเอง ซึ่งจะไม่ตรงกับความจริงภายในไม่กี่เดือน | สคริปต์ PowerShell + endpoint รับรายงาน + ตารางรอบการรายงาน |
| 4 | **สัญญาและลิขสิทธิ์** | ตอนนี้รู้ว่ามีซอฟต์แวร์อะไร แต่ยังไม่รู้ว่าซื้อมากี่สิทธิ์ ใช้เกินหรือยัง | ตาราง `contract`, `license`, VIEW เทียบจำนวนสิทธิ์กับการติดตั้ง |
| 5 | **แจ้งเตือนเข้า Microsoft Teams** | ประกันหมด งานซ่อมค้าง ซอฟต์แวร์ต้องห้าม ควรวิ่งเข้าหาคนไม่ใช่รอเปิดดู | Incoming Webhook + ตารางคิวแจ้งเตือน (กัน rate limit และส่งซ้ำ) |
| 6 | **รายงานและส่งออก PDF** | งานตรวจสอบภายในต้องการเอกสาร | เลือก library ฝั่งเซิร์ฟเวอร์ |
| 7 | **ตรวจนับทรัพย์สินประจำปี** | ใช้ QR ที่มีอยู่แล้วให้คุ้ม | ตาราง `stocktake` + หน้ามือถือโหมดนับ |

## ข้อควรระวังเมื่อขึ้นใช้งานจริง

1. **เปลี่ยนรหัสผ่านบัญชีตัวอย่างทันที** — `admin` / `tech` / `view` รหัส `trr1234` มีไว้ทดลองเท่านั้น
2. **`JWT_SECRET` ต้องเป็นค่าสุ่มยาว** — `setup.bat` สุ่มให้อัตโนมัติ ถ้าตั้งเอง อย่าใช้ค่าตัวอย่าง (เซิร์ฟเวอร์จะไม่ยอมเริ่มทำงาน)
3. **สำรองฐานข้อมูล** — ตั้ง `pg_dump` รายวันก่อนเปิดให้คนอื่นใช้
4. **ถ้าเปิดให้เข้าจากนอกองค์กร** ต้องมี HTTPS (reverse proxy) — ตอนนี้ระบบฟังที่ HTTP พอร์ต 3000 เท่านั้น
5. **ลบข้อมูลตัวอย่าง 40 รายการ** ก่อนเริ่มบันทึกของจริง หรือติดตั้งใหม่ด้วยตัวเลือก "สร้างตารางเปล่า"
