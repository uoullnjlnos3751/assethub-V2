# คู่มือการใช้งานระบบ AssetHub

## 1. การเข้าสู่ระบบ (Login)

### 1.1 ใช้รหัสอะไรในการเข้าสู่ระบบ?

ระบบ **AssetHub** ใช้ระบบ Active Directory (AD) ของบริษัทในการยืนยันตัวตน  
**รหัสผ่านที่ใช้คือรหัส Windows เดียวกับที่คุณใช้ login เข้าเครื่องคอมพิวเตอร์ทุกวัน**

| ช่องทาง | รูปแบบUsername | ตัวอย่าง |
|---------|----------------|----------|
| Windows Login | `domain\username` | `trrgroup\watchara.kid` |
| Web App Login | `username` เท่านั้น | `watchara.kid` |

### 1.2 ทำไมไม่มีหน้า Register / ตั้งรหัสผ่าน?

เนื่องจากระบบใช้ AD ในการยืนยันตัวตน:
- **ไม่ต้องสมัครสมาชิก** — ผู้ใช้ที่มี AD account ทุกคนสามารถ login ได้เลย
- **ไม่สามารถตั้งรหัสผ่านในแอพได้** — รหัสผ่านถูกจัดการโดย IT/AD Admin
- **รหัสผ่านหมดอายุ?** — ให้เปลี่ยนรหัสผ่าน Windows ตามนโยบายของบริษัท (กด Ctrl+Alt+Del → Change a password)
- **ลืมรหัสผ่าน?** — ติดต่อ IT เพื่อรีเซ็ตรหัสผ่าน AD

### 1.3 ขั้นตอนการ Login

1. เปิดเว็บเบราว์เซอร์ไปที่: `http://10.100.22.222:5173`
2. หน้า Login จะปรากฏ
3. กรอก **Username** (ชื่อผู้ใช้ Windows เช่น `watchara.kid`)
4. กรอก **Password** (รหัสผ่าน Windows)
5. กด **Sign In**
6. หากเข้าสู่ระบบสำเร็จ จะเข้าสู่หน้า Dashboard

## 2. ปัญหาที่พบบ่อย

### ❌ "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง"

| สาเหตุที่เป็นไปได้ | วิธีแก้ไข |
|-------------------|-----------|
| พิมพ์ Username ผิด | ตรวจสอบ Username ให้ถูกต้อง (ห้ามมี `trrgroup\` นำหน้า) |
| พิมพ์ รหัสผ่านผิด | ตรวจสอบ Caps Lock / ภาษาแป้นพิมพ์ |
| รหัสผ่านหมดอายุ | เปลี่ยนรหัสผ่าน Windows (Ctrl+Alt+Del → Change a password) |
| บัญชีถูกล็อค | ติดต่อ IT |
| AD Server มีปัญหา | ติดต่อ IT |

### ❌ เข้าเว็บไม่ได้ / Connection Refused

| สาเหตุ | วิธีแก้ไข |
|--------|-----------|
| Docker Desktop ไม่ได้รัน | เปิด Docker Desktop แล้วรอจน icon เขียว |
| แอพยังไม่พร้อม | รอสักครู่แล้วรีเฟรชหน้าเว็บ |
| Port 5173 ถูกใช้งาน | แจ้ง Admin เพื่อตรวจสอบ process ที่ค้าง |

## 3. กรณีผู้ใช้ที่ไม่มี AD Account

ระบบปัจจุบัน **ต้องมี AD Account ถึงจะเข้าใช้งานได้**  
สำหรับกรณีที่ผู้ใช้ไม่มี AD Account (เช่น พนักงานต่างแผนก, ผู้รับเหมา, ลูกค้า) มีแนวทางดังนี้:

### ทางเลือกที่ 1: ขอ AD Account จาก IT
- ติดต่อฝ่าย IT เพื่อสร้าง AD Account ให้ผู้ใช้
- เป็นวิธีที่แนะนำเพราะปลอดภัยและเป็นมาตรฐานของบริษัท

### ทางเลือกที่ 2: สร้าง Local User (Admin ทำได้ในระบบ)
> ✅ ระบบรองรับ Local User Login แล้ว (เพิ่มเมื่อ 22/05/2026)

Admin สามารถสร้างผู้ใช้แบบ Local (ไม่ต้องมี AD) ได้ที่:
**จัดการผู้ใช้ (Users) → เพิ่มผู้ใช้งานใหม่ → เลือกแท็บ "สร้างผู้ใช้แบบ Manual"**

ขั้นตอน:
1. ไปที่เมนู **จัดการผู้ใช้** (ต้องเป็น SuperAdmin หรือ IT Admin)
2. กดปุ่ม **เพิ่มผู้ใช้งานใหม่**
3. เลือกแท็บ **สร้างผู้ใช้แบบ Manual**
4. กรอกข้อมูล:
   - **Username** — ชื่อผู้ใช้สำหรับเข้าสู่ระบบ
   - **รหัสผ่าน** — ตั้งรหัสผ่าน (อย่างน้อย 4 ตัวอักษร)
   - **ชื่อ - นามสกุล** — ชื่อที่แสดงในระบบ
   - **อีเมล, แผนก, บทบาท** — ข้อมูลอื่นๆ (optional)
5. กด **เพิ่มเข้าระบบ**

ผู้ใช้ที่สร้างด้วยวิธีนี้จะสามารถ login ด้วย Username และรหัสผ่านที่กำหนด โดยไม่ต้องมี AD Account

### การตั้งรหัสผ่านให้ผู้ใช้ AD (เพิ่มเติม)
Admin สามารถตั้งรหัสผ่าน Local ให้กับผู้ใช้ AD ได้เช่นกัน ซึ่งจะทำให้ผู้ใช้สามารถ login ได้ทั้ง AD และ Local:
1. ไปที่ **จัดการผู้ใช้**
2. หาผู้ใช้ที่ต้องการ แล้วกด **ตั้งรหัส**
3. กรอกรหัสผ่านใหม่ → บันทึก

## 4. การออกจากระบบ

- คลิกที่เมนูผู้ใช้ที่มุมขวาบน → **Sign Out**
- หรือปิดเบราว์เซอร์ (ระบบจะออกจากระบบเมื่อหมดอายุ Session)

---

## 5. การแจ้งปัญหา / ขอความช่วยเหลือ

- **ปัญหา Login / AD** → ติดต่อ IT
- **ปัญหาเกี่ยวกับข้อมูลในระบบ** → แจ้ง IT Admin
- **ข้อเสนอแนะ / ต้องการฟีเจอร์เพิ่ม** → แจ้ง Admin ผ่านระบบหรืออีเมล
